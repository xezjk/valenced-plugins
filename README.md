# Valenced Discord Client Plugins

This repository contains a main branch with the source code of every plugin and a gh-pages branch made to serve the zipped plugins through the pages link.

https://xezjk.github.io/valenced-plugins/

## Plugins
### Animal Commands
This plugin adds multiple animals random images commands. It gets the images through different APIs and pastes the link in the text field, the image will display as preview. I recommend to only send the link and do not add text because then it would display the link also.

### Leave That Out!
This plugin automatically censors swears in your messages whilst you send them. There's a swear list and the plugin checks whether the message contsins any of those and censors them.

### Maths+
This plugin is really useful for quick Maths directly in the message. You can add to your message multiple wrappers like this: <<>> and put and write an expression between, the plugin will solve every wrapper on send. This plugin supports many symbols for every sign, you'll find yourself very comfortable with it. It has constants, functions and normal Maths. You can have a look in the solve typescript file in the plugin's directory to see every available symbol.
